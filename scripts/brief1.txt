1. Project Overview
1. Project Overview
Project name: Seekra marketing website (the public "product face").
Objective: Design and build a modern, corporate, professional single-page marketing website for Seekra, a
self-hosted, content-aware AI document intelligence platform. The site will be the primary marketing asset
for two target markets: the Gulf region (enterprise/government buyers who care about data sovereignty) and
Pakistan (enterprises and organizations needing bilingual English/Urdu/Arabic document AI).
Design ambition: An Apple.com-class scrolling experience — cinematic, spacious, confident — without
copying Apple. The page should keep visitors engaged as they scroll: a strong animated hero, alternating
dark and light chapters, subtle scroll-reveal motion, and honest product storytelling.
Deliverable expected from the build: A production-ready responsive website (desktop + mobile), English
first (Arabic version planned later), deployable as static files.
Hosting plan (context for the builder): The marketing site will live at the domain root seekra.pk; the
actual web application will move to app.seekra.pk. The site must therefore work at a domain root and
keep the "Launch App / Book a Demo" links configurable.
2. The Product: What Seekra Does
Seekra is a Content-Aware Intelligence platform: organizations upload their documents, and Seekra lets
staff ask questions, search by image, and even talk to their archive — with answers grounded in the
organization's own files and cited back to the exact source page. It is fully self-hosted: nothing leaves the
customer's infrastructure.

5. Website Structure & Content Requirements
Arabic text (used in small accent chips such as "ودرا · ﺔﻴﺑﺮﻌﻟا · English") must render with proper
shaping; include a Nastaliq/Naskh-capable font fallback for Urdu/Arabic snippets.
4.2 Visual language rules
Backgrounds are solid. No grid-line patterns, no square-box textures, no busy tech patterns. Depth
comes from soft radial glows (tan on charcoal/brown) and generous whitespace.
Rhythm: alternate dark and light chapters as the visitor scrolls (dark hero → light problem/capabilities
→ dark security wall → light comparison/deployment → dark contact/footer).
Motion: subtle scroll-reveal (fade + slight rise, staggered), slow crossfade/Ken-Burns on hero visuals.
Motion must be calm — no parallax gimmicks, no autoplaying sound.
Product visuals in browser-frame mockups: UI screenshots/videos sit inside a minimal browser-
chrome frame (three dots + URL pill showing app.seekra.pk) with soft tan-tinted shadows.
Corner radius: moderate (10–16px on cards/frames); no heavy shadows; borders hairline (rgba cream
at 8–12% on dark, gray on light).
Icons: thin-stroke line icons only (lucide-style), tan or currentColor.

7. Technical Requirements & Constraints
Stack (preferred): React + TypeScript + Vite + Tailwind CSS, producing a static build (dist/) that can
be served by any web server. A well-structured plain HTML/CSS/JS build is also acceptable if equally
polished.
No backend required for the site itself. The contact form uses a form-to-email service (FormSubmit
endpoint: https://formsubmit.co/ajax/rahmirz.consulting@gmail.com) with graceful
mailto: fallback and clear sending/sent/error states.
Fonts self-hosted (no Google Fonts CDN dependency at runtime preferred).
Performance: optimized images (progressive JPEG/WebP, <250KB each), lazy-load below-the-fold
media, no heavy animation libraries required for the current scope (IntersectionObserver + CSS
transitions suffice).
SEO basics: title "Seekra — Content-Aware Intelligence for the Enterprise", meta description, Open
Graph tags, semantic HTML, descriptive alt text.
Accessibility: sufficient contrast in both themes, focus states, reduced-motion media query honored.
Deployment target: static files behind nginx at the domain root; all asset paths relative; no client-side
router needed (single page, hash anchors only).
Internationalization: English first; keep copy centralized (single config/content file) so an Arabic (RTL)
version can be added later without restructuring components.

9. Copy Deck (Approved Messaging)
Cloud AI assistants are excellent generalists — but they ask you to hand them your documents. Seekra
brings the intelligence to your documents instead: it runs entirely on your infrastructure, masks personal
data before any model sees it, and proves every answer with a citation you can open.
The site must communicate this without disparaging competitors: the comparison table stays factual (data
residency, citations, visual search, offline capability), and a footnote acknowledges cloud tools' strengths for
general-purpose work.
