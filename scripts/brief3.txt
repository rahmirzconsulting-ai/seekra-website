6. Hard-Won Technical Lessons (read before any backend change)
1. Document ORM does not map collection_id(modelpredatescollections). doc.collection_id
→AttributeError→500. AlwaysrawSQL:SELECT id, collection_id FROM documents WHERE id =
ANY(CAST(:ids AS int[])) and merge into payload dicts. Defensive getattr(doc, "pii_flagged",
| ...) | pattern used | for the | same reason. |     |     |     |
| ---- | ------------ | ------- | ------------ | --- | --- | --- |
2. FastAPI response_model silently strips undeclared keys. list_files merges collec-
tion_id/status into dicts, but they vanish unless declared on DocumentResponse (Optional[...] =
| None). | This caused | two “invisible” | bugs | in a row | (18B5, 18B6). |     |
| ------ | ----------- | --------------- | ---- | -------- | ------------- | --- |

every payload-shape change and/or flush seekra:files:list:* in Redis after deploys, or stale
